# image-classifier
一个简单的 Python 脚本，用于根据图片的长宽比（横版/竖版）自动分类图片，并根据文件内容生成唯一的 6 位 Hash 进行重命名。

## 功能特点
- **自动分类**：识别图片比例，将其归类到 `landscape`（横版）或 `portrait`（竖版）文件夹。
- **Hash 重命名**：使用 MD5 哈希前 6 位命名，避免文件名混乱且能初步去重。
- **安全操作**：处理了 Windows 下的文件占用问题，支持移动（默认）或复制（`--keep`）模式。
- **自定义路径**：支持指定任意文件夹进行处理。

## 快速开始

### 安装依赖
```bash
pip install Pillow
```

### 使用方法
```bash
# 在当前目录执行（分类并移动文件）
python classify.py

# 指定路径并保留原文件（复制模式）
python classify.py /path/to/your/images --keep
```

## 参数说明
| 参数 | 说明 |
| :--- | :--- |
| `path` | 可选，目标文件夹路径，默认为当前目录 `.` |
| `--keep` | 可选，保留原文件（执行复制而非移动） |
